# Laboratorio Diésel - E-Commerce MVP 🚀

Plataforma web integral desarrollada para la digitalización del catálogo de repuestos e inyectores de **Laboratorio Diésel**. El sistema permite a los clientes buscar piezas por código OEM, armar un carrito de compras y generar pedidos estructurados directamente por WhatsApp.

## 📁 Documentación del Proyecto
Toda la documentación técnica y de requerimientos se encuentra en el directorio `/docs`:

* [Especificación de Requisitos de Software (SRS)](./docs/srs.md): Contiene el alcance del MVP, casos de uso, flujos y requisitos funcionales/no funcionales.
* [Descripción del Sistema](./docs/systemdescription.md): Arquitectura general y reglas de negocio del dominio.

## ⚙️ Características Principales (MVP)
* **Catálogo Público:** Búsqueda global por código OEM, marca y compatibilidad de vehículos.
* **Checkout Inteligente:** El carrito de compras compila el pedido y redirige al cliente a WhatsApp con un mensaje pre-formateado.
* **Backoffice Seguro:** Panel de administración con autenticación para el ABM (Alta, Baja y Modificación) de productos, categorías, subcategorías y visibilidad de precios.
