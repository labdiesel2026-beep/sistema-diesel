# Diesel Lab UI

Crea la interfaz de usuario (UI) para "Laboratorio Diésel", un e-commerce y taller de inyección diésel. 

Tecnologías: React + Tailwind CSS (con Lucide-React). 100% Mobile-First. No desarrolles backend, usa mock data.

ESTILO VISUAL GLOBAL:

- Primario: Azules técnicos (bg-slate-900, bg-blue-950).

- Acento: Azul eléctrico (bg-blue-600) para CTAs.

- Secundario: Verde WhatsApp (#25D366) para contacto.

- Estética: Limpia, industrial, alta gama, bordes rounded-xl.

VISTA 1 A MAQUETAR: LANDING PAGE INSTITUCIONAL

1. Navbar: Logo tipográfico "Laboratorio Diésel", links (Inicio, Servicios, Catálogo), botón de WhatsApp y un icono de Carrito (con un badge '0').

2. Hero Section: Título sobre precisión técnica y venta de inyectores Common Rail. Botones: "Ver Catálogo" y "Consultar por WhatsApp".

3. Servicios: 4 tarjetas simples (Diagnóstico, Banco de pruebas, Recambios, Repuestos).

4. Garantías: Sección breve explicando 30 días de garantía con botón verde "Solicitar Garantía (WhatsApp)".

5. Footer: Datos de contacto y un placeholder gris simulando un mapa de Google Maps.
